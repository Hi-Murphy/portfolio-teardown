Usage: pnpm perf:startup <url> | --serve <dir> --route <path> [options]

Measures engagement-driven 3D startup on the mobile profile with 4x CPU throttling.

Options:
  --serve <dir>       serve a static export on a free local port

`V8.CompileCode`, and `v8.parseOnBackground` (9 events in this run = 3 + 3 + 3).

thread, so it is not summed separately. Background parse contributes to P2.ms but not
P2.mainThreadMs. `FunctionCall` is not a P2 or P3 phase event: chunk FunctionCalls include
React render callbacks after mount, so P3 is defined only by depth-0 `moduleEval` spans from
the init script.
