Theme/motion: light + dark; normal motion for label/fade checks; reduced poster path covered by home:probe

## Implementation

- The active-step label and desktop leader are aria-hidden absolute overlays. Their position changes use transform only; static top/left are never updated after mount. Position reads come from hero-dom.ts.
- hero-label.ts owns exit -> swap -> enter. Exit reaches opacity 0 before the pending label is displayed; panelExit/panelEnter durations and easings come from xploder/motion. Reduced motion switches labels instantly.
- hero-caption.tsx keeps the permanent `{name} — {tagline}` project line and the accessible static caption. The pause button remains outside aria-hidden and after the primary link in Tab order.
- home-probe.ts uses `[data-hero-project-line]` as the permanent AC2 project signal; the overlay label is decorative.
