# T008.1 — I-01 no-JS numbered poster

## Issue and cause

- **Issue:** I-01 (Sev-2, AC5). With JavaScript disabled, `/` showed the imploded poster without the numbered frame path. Reduced-motion and Save-Data cells already showed the exploded poster.
- **Cause:** the two `TeardownPoster` elements switched only on `motion-reduce:` and `peer-data-[site-live-state=skipped]:`. Without JavaScript, the live state never becomes `skipped`.
- **Fix:** add `noscript:hidden` to the imploded poster and `noscript:block` to the exploded flow poster. Tailwind emits `@media (scripting:none)` for these variants, so JavaScript-enabled visitors are unaffected.
