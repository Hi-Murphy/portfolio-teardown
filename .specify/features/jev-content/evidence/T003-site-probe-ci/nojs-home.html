About

I build Android apps at ████████, focused on community features — plus the unglamorous work that decides whether an app feels fast: a customizable payment library on Google Play Billing, a resource controller that made dynamic lists behave, liveness, and macro-benchmarking of UI-layer resource use.

I measure before I believe. When an existing tool could not answer a question, I wrote the harness: an inspector for WebSocket traffic, and a benchmark for how coding agents decide what to read. Both started as side projects and ended up changing how I work.

This site is built the same way. Each project is an exploded view of how it is actually put together — layer by layer, component by component, with the numbers that came out of the measurements.
